Act 1 · Constraints

Constraints ข้อจำกัดที่กำหนดรูปแบบระบบ

1. เงินต้องถูกต้อง (ACID)

หักเหรียญ · ให้สิทธิ์อ่าน · แบ่งรายได้
ต้องอยู่ใน transaction เดียว พังขั้นไหน rollback ทั้งหมด

2. รูปคือ 95% ของทราฟฟิก

รูปไม่ผ่าน Go server บน Azure เพื่อเลี่ยงค่า egress
เก็บและส่งรูปจาก Cloudflare R2 (egress $0)

3. งบนักศึกษา (~$20/เดือน)

อยู่ในเครดิต Azure (budget alert $30)
ไม่ใช้ NAT Gateway, Bastion, Front Door, Redis

Act 4 · Architectural Trade-offs

Trade-offs ทำไมเลือกใช้ และทำไมตั้งใจตัดทิ้ง

ที่เลือกใช้ + เหตุผล

Cloudflare R2 egress $0 · ต้องดูแล 2 vendors

AKS + Envoy GW คุม network/HPA · แทน ingress-nginx ที่ EOL

PG16 Flexible ACID สำหรับเงิน · private subnet

ที่ตั้งใจตัดทิ้ง + เหตุผล

Redis PG query ~0.1ms · ยังไม่มีคอขวด

Message Queue ยังไม่มี async consumer

gRPC REST พอสำหรับงานภายใน
